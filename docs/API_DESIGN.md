# REST API Design & OpenAPI 3.1 Specification — Ozhzo Verse

*Document Classification: Definitive Source of Truth*  
*Base Protocol: HTTPS / RESTful JSON*  
*Base URL: `/api/v1`*  
*Target Audience: Backend Engineers, Frontend/Mobile Engineers, Integration Testers*

---

## 1. REST API Standards & Conventions

### 1.1. Common Headers
- `Authorization: Bearer <jwt_access_token>` (Required for all authenticated endpoints)
- `X-Request-ID: <uuid>` (Generated by client or gateway for distributed tracing)
- `Content-Type: application/json`

### 1.2. Standard Success Response Envelope
```json
{
  "success": true,
  "data": { ... },
  "meta": {
    "page": 1,
    "limit": 20,
    "total": 105,
    "has_next": true
  }
}
```

### 1.3. Standard Error Response Envelope
```json
{
  "success": false,
  "error": {
    "code": "PERMISSION_DENIED",
    "message": "You do not have permission to delete tasks in this home.",
    "details": {},
    "correlation_id": "req-838cd80b-99f2"
  }
}
```

### 2.1. Authentication (`/auth`)

#### `POST /auth/register`
- **Purpose**: Register a new user account.
- **Auth**: Public
- **Request Body**:
  ```json
  {
    "email": "user@example.com",
    "full_name": "Alex Rivera",
    "password": "SecurePassword123!"
  }
  ```
- **Validation**: Email RFC format, password $\ge 8$ chars with 1 number and 1 special char.
- **Response (201 Created)**:
  ```json
  {
    "success": true,
    "data": {
      "user_id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
      "email": "user@example.com",
      "access_token": "eyJhbGciOi...",
      "token_type": "bearer",
      "expires_in": 900
    }
  }
  ```
- **Errors**: `409 Conflict` (`EMAIL_ALREADY_EXISTS`), `422 Unprocessable Entity` (`INVALID_PASSWORD_COMPLEXITY`).

#### `POST /auth/login`
- **Purpose**: Authenticate credentials and receive token pair.
- **Auth**: Public (Rate-limited: 5 req/15 min)
- **Request Body**: `{"email": "user@example.com", "password": "SecurePassword123!"}`
- **Response (200 OK)**: Returns access token in payload; sets `refresh_token` in secure HTTP-only cookie.
- **Errors**: `401 Unauthorized` (`INVALID_CREDENTIALS`), `429 Too Many Requests`.

#### `POST /auth/refresh`
- **Purpose**: Rotate refresh token and obtain a new access token.
- **Auth**: Refresh Token in HTTP-only Cookie / Mobile Header.
- **Response (200 OK)**: Returns new `access_token` and rotates refresh token.

#### `POST /auth/logout`
- **Purpose**: Revoke active session in Redis.
- **Auth**: Bearer Token
- **Response (200 OK)**: `{"success": true, "data": {"message": "Logged out successfully"}}`

#### `POST /auth/forgot-password` & `POST /auth/reset-password`
- **Auth**: Public. Dispatches 15m single-use reset token and verifies new password.

### 2.3. Homes & Workspace (`/homes`)

#### `GET /homes`
- **Purpose**: List all homes the authenticated user belongs to.
- **Auth**: Bearer Token
- **Response (200 OK)**: Array of Home membership summaries.

#### `POST /homes`
- **Purpose**: Provision a new Home workspace (Caller becomes `OWNER`).
- **Auth**: Bearer Token
- **Request Body**:
  ```json
  {
    "name": "Rivera Family Home",
    "currency": "USD",
    "timezone": "America/New_York",
    "address": "123 Maple St, Springfield"
  }
  ```
- **Response (201 Created)**: Returns created `Home` DTO.
- **Errors**: `402 Payment Required` (`FREE_TIER_HOME_LIMIT_REACHED`).

#### `GET /homes/{home_id}`
- **Purpose**: Retrieve home details and configuration.
- **Auth**: Bearer Token (`home:view`)
- **Response (200 OK)**: Detailed Home DTO.

#### `PATCH /homes/{home_id}`
- **Purpose**: Update home name, avatar, currency, timezone, or address.
- **Auth**: Bearer Token (`home:edit` $\rightarrow$ `OWNER`, `ADMIN`).

#### `DELETE /homes/{home_id}`
- **Purpose**: Soft delete or archive home workspace.
- **Auth**: Bearer Token (`home:delete` $\rightarrow$ `OWNER` only).

### 2.4. Members & Roles (`/homes/{home_id}/members`)

#### `GET /homes/{home_id}/members`
- **Purpose**: List all household members and assigned roles.
- **Auth**: Bearer Token (`members:view`)
- **Response (200 OK)**: Array of members with `user_id`, `display_name`, `avatar_url`, `role`, `status`, `joined_at`.

#### `PATCH /homes/{home_id}/members/{user_id}`
- **Purpose**: Update a member's assigned role.
- **Auth**: Bearer Token (`members:edit` $\rightarrow$ `OWNER`, `ADMIN`).
- **Request Body**: `{"role": "ADMIN"}`
- **Errors**: `403 Forbidden` (`CANNOT_MODIFY_OWNER_ROLE`).

#### `DELETE /homes/{home_id}/members/{user_id}`
- **Purpose**: Remove a member from the home workspace.
- **Auth**: Bearer Token (`members:remove` $\rightarrow$ `OWNER`, `ADMIN`).

#### `POST /homes/{home_id}/leave`
- **Purpose**: Voluntarily leave a home workspace.
- **Auth**: Bearer Token (Any non-owner member).

### 2.5. Invitations (`/homes/{home_id}/invitations` & `/invitations`)

#### `POST /homes/{home_id}/invitations`
- **Purpose**: Generate an invitation link or send an invite email.
- **Auth**: Bearer Token (`members:invite` $\rightarrow$ `OWNER`, `ADMIN`).
- **Request Body**:
  ```json
  {
    "email": "morgan@example.com",
    "role": "ADULT_MEMBER"
  }
  ```
- **Response (201 Created)**: Returns `invite_token`, `invite_url`, and `expires_at` (7 days).
- **Errors**: `402 Payment Required` (`MEMBER_LIMIT_EXCEEDED`).

#### `POST /invitations/{invite_token}/accept`
- **Purpose**: Accept an invitation token and join target home.
- **Auth**: Bearer Token (Authenticated user).
- **Response (200 OK)**: Returns joined Home and assigned role.
- **Errors**: `410 Gone` (`INVITATION_EXPIRED_OR_REVOKED`).

### 2.6. Household Inventory (`/homes/{home_id}/inventory`)

#### `GET /homes/{home_id}/inventory/items`
- **Purpose**: List inventory items with filtering and sorting.
- **Auth**: Bearer Token (`inventory:view`)
- **Query Params**:
  - `category_id` (UUID, optional)
  - `status` (`IN_STOCK`, `LOW_STOCK`, `OUT_OF_STOCK`, `EXPIRED`, optional)
  - `search` (string, optional)
  - `page` (int, default 1), `limit` (int, default 50)
  - `sort_by` (`name`, `quantity`, `expiry_date`, default `name`)
  - `sort_order` (`asc`, `desc`, default `asc`)
- **Response (200 OK)**: Paginated array of `InventoryItem` DTOs.

#### `POST /homes/{home_id}/inventory/items`
- **Purpose**: Add a new inventory item.
- **Auth**: Bearer Token (`inventory:create`)
- **Request Body**:
  ```json
  {
    "category_id": "2fa85f64-...",
    "name": "Almond Milk",
    "quantity": 2.0,
    "unit": "liters",
    "min_threshold": 1.0,
    "expiry_date": "2026-08-25"
  }
  ```
- **Response (201 Created)**: Returns created `InventoryItem` DTO.

#### `PATCH /homes/{home_id}/inventory/items/{item_id}`
- **Purpose**: Update quantity, threshold, or expiry date.
- **Auth**: Bearer Token (`inventory:edit`)

#### `POST /homes/{home_id}/inventory/items/{item_id}/add-to-shopping`
- **Purpose**: Quick-add inventory item to the active shopping list.
- **Auth**: Bearer Token (`shopping:create`)
- **Request Body**: `{"list_id": "optional-uuid", "quantity_to_buy": 2.0}`

### 2.8. Tasks & Household Responsibilities (`/homes/{home_id}/tasks`)

#### `GET /homes/{home_id}/tasks`
- **Purpose**: List household tasks with time-window views and status filters.
- **Auth**: Bearer Token (`tasks:view`)
- **Query Params**: `view` (`all`, `today`, `upcoming`, `overdue`, `my_tasks`, `completed`), `status` (`TODO`, `IN_PROGRESS`, `COMPLETED`, `CANCELLED`), `assigned_to` (UUID), `priority` (`LOW`, `NORMAL`, `HIGH`, `URGENT`), `page`, `page_size`

#### `POST /homes/{home_id}/tasks`
- **Purpose**: Quick task creation (title only required; other fields optional).
- **Auth**: Bearer Token (`tasks:create`)
- **Request Body**:
  ```json
  {
    "title": "Clean water filter",
    "description": "Replace sediment pre-filter candle and sanitize bowl",
    "priority": "NORMAL",
    "assigned_to": "3fa85f64-...",
    "due_date": "2026-08-20T18:00:00Z",
    "recurrence_type": "CUSTOM_DAYS",
    "recurrence_interval_days": 30,
    "recurrence_strategy": "COMPLETION_DATE"
  }
  ```
- **Response (201 Created)**: Returns created `Task` DTO.

#### `POST /homes/{home_id}/tasks/{task_id}/complete`
- **Purpose**: Mark task as completed (captures `completed_by`/`completed_at`, advances recurring cycle).
- **Auth**: Bearer Token (`tasks:complete`)
- **Response (200 OK)**: Returns updated completed task and spawned next recurrence instance.

#### `GET /homes/{home_id}/tasks/summary`
- **Purpose**: Key KPI summary metrics (`due_today`, `overdue`, `upcoming`, `my_tasks`, `completed_history_count`).
- **Auth**: Bearer Token (`tasks:view`)

### 2.9. Bills & Recurring Household Expenses (`/homes/{home_id}/bills`)

#### `GET /homes/{home_id}/bills`
- **Purpose**: List household financial obligations with time-window filtering.
- **Auth**: Bearer Token (`bills:view`)
- **Query Params**: `view` (`all`, `due_today`, `overdue`, `upcoming`, `paid`, `my_responsible`), `status` (`UNPAID`, `PARTIALLY_PAID`, `PAID`, `CANCELLED`), `category_id` (UUID), `responsible_member_id` (UUID), `search`, `page`, `page_size`

#### `POST /homes/{home_id}/bills`
- **Purpose**: Register a household bill or recurring expense obligation.
- **Auth**: Bearer Token (`bills:create`)
- **Request Body**:
  ```json
  {
    "title": "Electricity Bill",
    "expected_amount": "2000.00",
    "currency": "INR",
    "due_date": "2026-08-20",
    "recurrence_type": "MONTHLY",
    "recurrence_strategy": "SCHEDULED_DATE",
    "responsible_member_id": "3fa85f64-..."
  }
  ```
- **Response (201 Created)**: Returns created `Bill` DTO.

#### `POST /homes/{home_id}/bills/{bill_id}/payments`
- **Purpose**: Record full or partial payment against a bill (appends immutable ledger row and advances recurring cycle if fully paid).
- **Auth**: Bearer Token (`bills:pay`)
- **Request Body**:
  ```json
  {
    "amount_paid": "2137.00",
    "currency": "INR",
    "paid_date": "2026-08-12",
    "payment_method": "UPI",
    "notes": "Paid via GooglePay"
  }
  ```
- **Response (200 OK)**: Returns updated `Bill` DTO with new payment entry and balance.

#### `GET /homes/{home_id}/bills/summary`
- **Purpose**: Key financial KPI metrics (`due_today_count`, `due_today_amount`, `overdue_count`, `overdue_amount`, `upcoming_count`, `upcoming_amount`, `paid_this_month_count`, `paid_this_month_amount`).
- **Auth**: Bearer Token (`bills:view`)

  title: Ozhzo Verse REST API
  description: The Digital Operating System for Homes — Core Backend API
  version: 1.0.0

  - url: https://api.ozhzoverse.com/api/v1
    description: Production API Gateway
  - url: http://localhost:8000/api/v1
    description: Local Docker Environment

  - BearerAuth: []

components:
  securitySchemes:
    BearerAuth:
      type: http
      scheme: bearer
      bearerFormat: JWT

  schemas:
    StandardSuccess:
      type: object
      properties:
        success:
          type: boolean
          example: true
        data:
          type: object

          type: object

    StandardError:
      type: object
      properties:
        success:
          type: boolean

          type: object

              type: string

              type: string

    UserDTO:
      type: object
      properties:
        id:
          type: string
          format: uuid
        email:
          type: string
          format: email
        display_name:
          type: string
        avatar_url:
          type: string

          type: string

      type: object
      properties:

          type: string
          format: uuid

          type: string
          format: uuid

          type: string

          type: string

                $ref: '#/components/schemas/StandardSuccess'
