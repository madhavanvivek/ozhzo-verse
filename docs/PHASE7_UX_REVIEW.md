# Ozhzo Verse — Phase 7: UX Design Review & Design System Harmony

## 1. Design System Tokens & Brand Standards

| Category | Token / Specification | Usage & Rule |
|---|---|---|
| **Primary Brand** | Indigo-950 (`#0f172a` / `#1e1b4b`) | Core headers, primary action buttons, active navigation states. |
| **Accent / Focus** | Warm Gold / Honey (`#d97706` / `#f59e0b`) | Warning states, financial due dates, pending badges. |
| **Success / In-Stock** | Forest Emerald (`#15803d` / `#10b981`) | In-stock inventory, completed tasks, paid bills, accepted RSVPs. |
| **Urgent / Overdue** | Deep Terracotta (`#b91c1c` / `#ef4444`) | Overdue bills, overdue chores, empty pantry stock. |
| **Typography** | `Inter` / `system-ui` | Clean, highly legible sans-serif with proper tracking and hierarchy. |
| **Touch Targets** | Min `44 x 44 px` | Enforced on all mobile buttons, checkbox triggers, and preset chips. |
